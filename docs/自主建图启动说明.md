# 自主建图启动说明

## 1. 在机器人本机桌面终端选择自主建图工作空间

在机器人终端中执行：

```bash
cd ~/zzj_ws
source install/setup.bash
```

`install/setup.bash` 的环境 hook 会过滤它处理的 `*/install/nav2_*`、
`dwb_*`、`nav_2d_*` 等路径，保留 `/opt/ros/humble` 与未匹配的
当前/其他工作空间路径，但不保证隔离所有 overlay。自主启动入口还会检查
`nav2_bringup` 和 `nav2_mppi_controller` 的包前缀是否为 `/opt/ros/humble`。
这些操作不会修改共享的 `.bashrc`。

## 2. 启动自主建图

```bash
ros2 launch my_robot_bringup_fastlio autonomous_exploration.launch.py start_rviz:=true
```

## 3. 停止与退出

- 按 `Ctrl+C` 停止自主建图。
- 如需退出干净 Bash 环境，执行：

```bash
exit
```

底盘驱动由 `robot-base.service` 常驻管理，停止自主建图不会停止底盘服务。

## 注意

- RViz 是可选组件。恢复后的开发 launch 默认启动 RViz（`start_rviz=true`），
  需要可视化时请在机器人本机桌面终端执行。
- 从 Mac 使用普通 SSH 启动时没有图形显示环境，请显式加
  `start_rviz:=false`（无显示/资源受限场景同样适用）。
- Web 后端启动自主建图时应使用同一套 `install/setup.bash`，并传入
  `start_rviz:=false`。
