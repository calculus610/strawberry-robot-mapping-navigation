# 自主建图启动说明

## 1. 在机器人本机桌面终端选择自主建图工作空间

在机器人终端中执行：

```bash
cd ~/zzj_ws
source install/setup.bash
```

`install/setup.bash` 会自动移除其他工作空间中重复的 Nav2/DWB 路径，
但保留导航组、Web 和 Autoware 的其他包。它不会修改共享的 `.bashrc`。

## 2. 启动自主建图

```bash
ros2 launch my_robot_bringup_fastlio autonomous_exploration.launch.py start_rviz:=true
```

## 3. 停止与退出

- 按 `Ctrl+C` 停止自主建图。
- 如需退出干净 Bash 环境，执行：

```bash
exit
```

底盘驱动由 `robot-base.service` 常驻管理，停止自主建图不会停止底盘服务。

## 注意

- 需要看到 RViz 时，请在机器人本机桌面终端执行。
- 从 Mac 使用普通 SSH 启动时没有图形显示环境，因此不会显示 RViz。
- Web 后端启动自主建图时应使用同一套 `install/setup.bash`，并传入
  `start_rviz:=false`。
